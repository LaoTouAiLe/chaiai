## 范围

本轮按用户确认的桌面工作台方向调整前端：暖灰侧栏、白色内容区、中性主操作、统一的阅读列与输入区，以及浅深两套主题。参考目录为 Codex CLI 仓库，没有找到其桌面前端，因此没有声称复用了桌面源码。

主要修改：

- `local-agent-web/frontend/src/styles/tokens.css`：颜色、字号、布局尺寸、圆角与共享阴影。
- `src/app/`：桌面内容区外壳；把已有功能页状态传给侧栏，仅表达当前导航位置。
- `src/components/`：侧栏、顶栏、输入框与共用控件。
- `src/features/`：对话欢迎区、正文和代码块，设置、任务、数据中台、能力、产物、定时任务、轨迹、审批与右侧工作面板的呈现。
- `docs/plans/UI_PAGE_IMPLEMENTATION.md`：记录本轮覆盖旧版视觉尺寸的约定。

未修改后端、接口契约、执行流程、权限与审批语义、草稿保存、记忆或数据生命周期。审批区域只调整布局：提示独占一行，按钮不收缩、不换行；深色主操作使用反色文字。

## 范围外发现（仅记录）

`local-agent-web/scripts/serve_fake.py:133` 的 `--data` 只指定配置/工作区目录；`_write_config` 保留了示例中的空 `data_root`，随后 `serve_fake.py:175` 装配仍按平台数据根定位数据库。未设置 `CHAIAI_HOME` 时，本轮首次启动因此试图创建平台数据目录并被文件权限拒绝。

本轮通过进程级 `CHAIAI_HOME` 显式隔离验收数据，未修改该脚本或后端路径逻辑。后续如修复测试启动脚本，需要单独处理其数据根隔离。
