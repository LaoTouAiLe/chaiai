## 1. 范围

### 1.1 做什么

在 v0.4 的页面壳上**深化**，不重建：

1. **多会话并行状态**：会话列表/侧栏直接看出"哪个会话在跑、哪个在等你"（现在只有任务中心一页能看到，见 v0.6 T62）。
2. **断线重连与会话恢复**：断线→重连→**以权威快照为准**，事件只做增量；页面按事件标识去重，不重复显示、不重复触发工具与审批。
3. **工具时间线 / diff / 计划的深化**：长输出折叠、大结果分页（复用 §6.7 的 locator 与 `read_file` 行区间，**不新增读取通道**）。
4. **流式降级**：关闭流式时仍拿到完整结果；同一提问在两条路径下业务结果应逐字段一致。
5. **等待用户处理的集中入口**：审批 / `needs_review` 汇总并"跳到那个会话处理"，**不建第二套审批界面**（§17.6）。
6. **负例收口**：伪造前端请求（改参数、跳过按钮、重放事件）**不能绕过**权限与审批；v0.4 页面与 v0.8 增强共享同一应用服务回归集。

### 1.2 这次不做

默认公网监听、多人账号、云端同步（`FUTURE_WORK.md:422`）；**不重写** v0.4 页面壳；不建第二套真源、第二套审批界面、第二套任务中心；不做自然语言路由；不新增付费调用。
