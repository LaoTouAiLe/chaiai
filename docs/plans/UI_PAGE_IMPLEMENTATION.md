## 1. 总则

### 1.1 目标（按优先级）

1. **可读**：所有承载信息的文字对比度达标，不再出现"远看一片脏灰"。
2. **有骨相**：用留白和一条细线分组，不用一堆边框和圆角把页面切成碎块。
3. **一致**：一个按钮、一个状态标签、一种关闭方式、一套图标网格。同一种东西永远长同一个样。
4. **克制**：动效只解释状态变化，不制造表演；反馈在当帧发生。
5. **可落地**：每条规则都能被代码或检查脚本验证，见 §10。

### 1.2 五条硬规则（违反即视为缺陷，不接受"这次特殊"）

| # | 规则 | 判据 |
|---|---|---|
| R1 | **扁平，不套框**。禁止卡片套卡片；面板内部除必要外不加分隔线。分组靠留白 + 单条 hairline。 | 设置页可见 1px 边框数 ≤ 现状的 40% |
| R2 | **一个原语，一个职责**。按钮、状态标签、搜索框、空态、确认框各只有一个实现，新代码不得 fork。 | `components/ui/` 之外不得出现自绘按钮/标签 |
| R3 | **不透明实色**。面板、卡片、浮层、文字一律用实色。禁止用 alpha 直接定义 surface 或文本色。 | surface/text token 值必须是 `#RRGGBB`，不得含 alpha |
| R4 | **Token 优先**。间距、字号、圆角、颜色不得写字面量。 | `*.module.css` 中 spacing 字面量 ≤ 30 处（现状约 135） |
| R5 | **一个图标网格**。统一 16px 视觉尺寸、`viewBox="0 0 24 24"`、线宽 1.5。 | 全仓不出现第二套 viewBox |

### 1.3 与 Hermes 的对齐边界（重要）

用户要求"视觉表现与交互质感对齐 Hermes，但不照搬底色"。执行口径如下：

| 维度 | 处理 | 说明 |
|---|---|---|
| 信息架构（页面/覆盖层/面板三分） | **对齐** | 见 `DESIGN.md:46-59` |
| 扁平化与边界处理 | **对齐** | `DESIGN.md:27-31`、`:289-292` |
| 组件收敛（单原语） | **对齐** | `DESIGN.md:32-34` |
| 悬浮层统一高度 | **对齐** | `DESIGN.md:82-92` |
| 动效纪律（hover 即时、返回缓动） | **对齐** | `DESIGN.md:467-473` |
| 工具提示的时机与克制 | **对齐** | `DESIGN.md:184-214` |
| 空态/错误/加载的统一原语 | **对齐** | `DESIGN.md:323-345` |
| 对话区密度（小字号 + 紧行高） | **对齐** | `styles.css:511-524` 实测 13px×110%≈14.3px，行高 1.38 |
| **底色与配色** | **自研** | Hermes 用 `color-mix(..., transparent)` 派生文本色（`styles.css:364-367`）+ 29% 玻璃窗（`DESIGN.md:139-146`）。**全部改为不透明实色**，见 §2.1 |
| **字体** | **自研** | Hermes 内置 Inter/Spectral/Fraunces 等英文字体包；中文界面套用会失真。保留系统中文栈 |
| **圆角** | **自研** | Hermes `--radius-scalar: 0.2`（`styles.css:501`）→ 主圆角 2px，近乎直角。我们取 4/6/10，保留少量柔和但去掉"软糖感" |
| 布局引擎（pane 树 / 任意分屏） | **不采用** | 右栏按 `WORK_PANEL_PLAN.md` 的固定多标签容器，见 §5.4 |
| 多主题 / 主题市场 / 9 语言 | **不采用** | 单机中文自用，只保留浅/深两套 |
| 毛玻璃、HUD、宠物 | **不采用** | 桌面端形态红利，Web 无收益 |

### 1.4 术语

- **壳（Shell）**：侧栏 + 顶栏 + 中栏 + 右栏的常驻骨架。
- **页（Page）**：中栏内的整页内容（对话 / 轨迹 / 会话地图 / 能力中心 / 产物 / 定时任务）。
- **覆盖层（Overlay）**：设置、数据中台、任务中心、命令面板、确认框。打开时压在当前页上，关闭回到原页。
- **面板（Panel）**：右栏多标签容器，随当前任务存在，收起不销毁。
- **原语（Primitive）**：`components/ui/` 下的唯一实现，禁止调用点覆写其尺寸/圆角/内边距。

## 2. 视觉基础（Design Tokens）

### 2.1 配色：不透明方案

设计意图：Hermes 的观感是"硬骨架 + 留白"，靠的是近乎直角的边界和高对比文字；它的底色用半透明是为了桌面玻璃效果，在 Web 上会露出背景、显得脏、且无法预测。本方案改为**实色分层**：三层中性底 + 一条 hairline + 四级文字，全部实色。

#### 浅色（默认）

```css
:root {
  /* 底层 surface：三层，靠明度差区分，不靠边框 */
  --c-canvas:        #ffffff;  /* 对话区、内容主底 */
  --c-panel:         #f7f8fa;  /* 侧栏、右栏、顶栏 */
  --c-raised:        #ffffff;  /* 浮层、下拉、弹窗表面 */
  --c-sunken:        #f1f3f6;  /* 输入框、代码块、只读区 */
  --c-hover:         #eef0f4;  /* hover 实色替代 alpha */

  /* 边界：只有一条默认 hairline */
  --c-line:          #e3e6eb;
  --c-line-strong:   #d2d7de;

  /* 文字：四级，承载信息的只有前三级 */
  --c-text-1:        #14171c;  /* 正文、标题        17.0:1 */
  --c-text-2:        #4a5058;  /* 次级正文、列表副行  8.1:1 */
  --c-text-3:        #6b7280;  /* 元信息、时间、工具行 4.8:1 */
  --c-text-off:      #9ca3af;  /* 仅禁用态与纯装饰，禁止承载信息 */

  /* 强调与语义 */
  --c-accent:        #2563eb;  /* 5.2:1，可作文字与描边 */
  --c-accent-soft:   #eff4ff;
  --c-success:       #12805c;  /* 4.9:1 */
  --c-success-soft:  #e9f7f1;
  --c-warn:          #b45309;  /* 5.0:1 */
  --c-warn-soft:     #fdf5e9;
  --c-danger:        #c62828;  /* 5.6:1 */
  --c-danger-soft:   #fdeeee;

  /* 遮罩：全站唯一允许的 alpha */
  --c-scrim:         #0b0d1280;
}
```

#### 深色

```css

  --c-panel:         #16181d;
  --c-raised:        #1c1f25;
  --c-sunken:        #0d0f13;
  --c-hover:         #22262e;

  --c-line:          #262a31;
  --c-line-strong:   #333842;

  --c-text-1:        #e9ecf1;  /* 15.3:1 */
  --c-text-2:        #a8b0bc;  /*  8.0:1 */
  --c-text-3:        #7c8695;  /*  4.6:1 */
  --c-text-off:      #5a6270;

  --c-accent:        #6e9bff;
  --c-accent-soft:   #1a2438;
  --c-success:       #3dd68c;
  --c-success-soft:  #12271e;
  --c-warn:          #f0a742;
  --c-warn-soft:     #2b2112;
  --c-danger:        #ff6b6b;

  --c-scrim:         #000000a6;

```

#### 深浅切换策略（2026-10-22 拍板）

- **默认跟随系统**：`prefers-color-scheme` 为 `dark` 时挂 `data-theme="dark"`，否则 `data-theme="light"`。
- **手动覆盖优先**：用户在设置里显式选择浅色/深色后，写入 `localStorage`（沿用现有偏好存储），此后不再跟随系统；选择"跟随系统"则清除该覆盖。
- 切换不得触发整页重载；`color-scheme` 属性随 `data-theme` 同步，保证原生滚动条、输入框、日期控件一致。
- 首次渲染前需在 `index.html` 内联一段最小脚本设置 `data-theme`，避免亮色闪一帧（FOUC）。

**Alpha 的合法用途**（R3 的唯一例外，且必须叠在不透明底上）：
- 遮罩 `--c-scrim`
- 图像上叠的渐变（如气泡内图片底）
- 禁用态的整体 `opacity: 0.5`（作用于已渲染的不透明层）

**禁止**：`rgba(0,0,0,.04)` 直接当卡片底色、`color-mix(..., transparent)` 派生文字色、半透明面板。

#### 对比度基线（浅色，白底，已核算）

| Token | 值 | 对比度 | 允许用途 |
|---|---|---|---|
| `--c-text-1` | `#14171c` | 17.0:1 | 正文、标题、按钮文字 |
| `--c-text-2` | `#4a5058` | 8.1:1 | 列表副行、说明文字 |
| `--c-text-3` | `#6b7280` | 4.8:1 | 时间戳、工具行、元信息、占位符 |
| `--c-text-off` | `#9ca3af` | 2.8:1 | **仅**禁用态、分割装饰 |
| `--c-accent` | `#2563eb` | 5.2:1 | 链接、可点文字 |
| `--c-danger` | `#c62828` | 5.6:1 | 错误文字、危险按钮文字 |

> 现状对照：`--law-text-caption: #adb2b8` 仅为 **2.1:1**（`tokens.css:80`），`shell.png` 里工具行、时间戳、耗时全落在这一档，这是"脏灰"观感的主因。
> 深色见上式注释；全部值须用 axe 复核（§10.4）。

### 2.2 字体

```css
--font-ui: -apple-system, BlinkMacSystemFont, 'Segoe UI Variable Text', 'Segoe UI',
           'PingFang SC', 'Microsoft YaHei UI', 'Microsoft YaHei', sans-serif;
--font-mono: 'JetBrains Mono', 'Cascadia Mono', 'SF Mono', Consolas,
             'Microsoft YaHei Mono', monospace;
```

- 中文一律走系统字体，不引入 Web 字体（体积 + 首屏抖动不值得）。
- 代码、路径、ID、耗时、token 数一律 `--font-mono`，字号比同级正文小 1px。
- 禁止在正文里用 `font-weight: 300`（Windows 上中文细体渲染发虚）。

### 2.3 字号与行高

| Token | 字号 | 行高 | 用途 |
|---|---|---|---|
| `--fs-caption` | 11px | 16px | 仅装饰性小字（标签角标） |
| `--fs-meta` | 12px | 18px | 时间戳、工具行、列表副行、按钮小号 |
| `--fs-body` | 13px | 20px | 列表主行、表单标签、侧栏会话标题 |
| `--fs-ui` | 14px | 20px | 按钮、输入框、菜单项 |
| `--fs-chat` | 14px | **21px** | 对话正文（行高比 1.5，比现状 22px 收紧） |
| `--fs-title` | 15px | 22px | 会话标题、弹窗标题 |
| `--fs-heading` | 18px | 26px | 页面级标题 |
| `--fs-display` | 26px | 34px | 空态主标题 |

> **修正记录**：初版建议把对话正文放大到 15px。核对 Hermes 实测值后推翻——它正文 13px×110%≈14.3px、行高 1.38（`styles.css:511-524`），比我们更小更紧。观感差异来自**对比度与行高**，不是字号。故正文保持 14px，只把行高 22→21、颜色抬到 `--c-text-1`。**2026-10-22 拍板确认：接受 14px 不放大**，先落对比度与行高再看效果，若仍显吃力再单独评估。

### 2.4 间距

基准 4px：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 56`。

| 场景 | 值 |
|---|---|
| 页面横向留白 | `clamp(20px, 4vw, 64px)`（对齐 `layout-constants.ts:9` 的意图） |
| 区块之间 | 32 |
| 区块标题与内容 | 12 |
| 列表行内边距 | 上下 8，左右 12 |
| 列表行高（会话） | 34（沿用 `tokens.css:182`） |
| 弹窗内边距 | 24 |
| 表单字段之间 | 20 |
| 图标与文字 | 8 |

### 2.5 圆角（与 Hermes 的关键差异）

| Token | 值 | 用途 |
|---|---|---|
| `--r-control` | 4px | 按钮、输入框、下拉触发器、标签 |
| `--r-panel` | 6px | 面板、代码块、图片容器 |
| `--r-overlay` | 10px | 弹窗、下拉面板、浮层 |
| `--r-pill` | 999px | 状态点、头像 |

**规则**：同一屏内圆角种类不超过 3 种（现状 7 档）。卡片不再用 12/16px 大圆角——大圆角 + 边框是"软塌"观感的主要来源。

### 2.6 边界与阴影

- **默认无边框**。需要分隔时用 `1px solid var(--c-line)`，且只在"分组之间"，不在"每一行之间"。
- 悬浮层统一两级：

```css
--sh-overlay: 0 0 0 1px #0000000f, 0 8px 24px #1018281a, 0 2px 6px #1018280f;
--sh-menu:    0 0 0 1px #00000012, 0 4px 12px #10182814;
```

- 禁止为单个组件写一次性 `box-shadow`。
- 卡片**没有阴影**（现状设置页卡片有淡阴影，改为纯色 surface）。

### 2.7 动效

| 场景 | 时长 | 曲线 |
|---|---|---|
| hover 进入 | 0ms（当帧） | — |
| hover 离开 | 100ms | `ease-out` |
| 面板展开/收起 | 200ms | `cubic-bezier(.2,0,0,1)` |
| 弹窗进入 | 150ms（透明度 + `scale(.98→1)`） | `ease-out` |
| 审批卡上浮 | 220ms | `cubic-bezier(.2,0,0,1)` |
| 骨架屏呼吸 | 1200ms 循环 | `ease-in-out` |

- `prefers-reduced-motion: reduce` 或用户偏好"减少动效"时，全部降到 0ms，不做替代动画。
- 禁止 `transition-all`；只写具体属性。

## 4. 壳（Shell）

### 4.1 侧栏

结构（自上而下，间距 8）：

1. **品牌行 48px**：左侧 24×24 标记 + `chaiai`（`--fs-body`，`--c-text-1`，字重 600）；右侧收起按钮（`⌘`/`Ctrl+B`）。
2. **新建会话按钮**：高 34，整宽，`--c-raised` 底 + `--c-line` 边 + `--r-control`。左侧 `+` 图标，文字 13px。hover 换 `--c-hover`。**不做下拉**（我们无 pane 落点，多窗口/多标签不适用）。
3. **搜索框**：高 32，无边框，`--c-sunken` 底，左侧放大镜，占位符 `搜索会话…`（`--c-text-3`）。有输入时右侧出现 `×` 清除。**注意**：现状是纯客户端过滤（`Sidebar.tsx:126-138`），在服务端搜索落地前，占位符保持"搜索已加载会话"，不得写成"搜索全部会话"。
4. **工作区分组**：
   - 组标题行：`local-agent-web`（小写、13px、`--c-text-2`、字重 500）+ 右侧 `+`（添加工作区，hover 才显示）。**不再是"工作区"这个功能名当头**——功能名与数据名重复出现是现状的视觉噪音。
   - 会话行 34px：状态点 6px（左）+ 标题（13px，`--c-text-1`，溢出省略）+ 右侧元信息（12px，`--c-text-3`：`刚刚` / `3 分钟` / 状态词）。
   - 当前会话：`--c-hover` 实色底 + 左侧 2px `--c-accent` 竖条。
   - 运行中会话：标题后加一个 8px 的 `--c-accent` 旋转指示（不用绿色点，绿点留给"已完成"）。
   - 每行 hover 才显示 `…` 菜单。
5. **`展示更多（n）`**：文字按钮，12px，`--c-text-3`，居中，高 28。
6. **已归档分组**：折叠，标题行可点，展开后行样式同会话行但整体 `--c-text-2`。
7. **底部入口区**（距底 12，上下 hairline）：
   - 任务中心（带角标）、数据中台、能力中心、设置——**四个**，高 36，图标 16 + 文字 13。
   - 角标：`--c-danger` 实心圆，白字 11px，`--r-pill`。

**收起态**：只留图标列宽 56，图标居中；品牌行只留标记；新建按钮变成一个 34×34 的 `+`；tooltip 右侧弹出。

### 4.2 顶栏

三段式，左右各 `clamp(20px,4vw,64px)` 内边距：

| 区域 | 内容 | 规则 |
|---|---|---|
| 左 | 工作区名（12px，`--c-text-3`）+ 会话标题（15px，`--c-text-1`，字重 600） | 两行，垂直居中对齐行首；标题单行省略 |

这条不是纯 UI 决定，它改的是审批语义，落地前必须先在 `ARCHITECTURE.md` 记录（现有 `:128` 要求外部写逐次审批），再编码。需要写清的三点：

1. **判定时机**：调度触发时先按当前权限档位与目录授权做一次预检；预检失败则不启动会话，直接记为 `blocked`，运行记录写明被哪条策略拦下。

3. **投递通道**：第一版只有"本地运行记录"一个出口。不实现 Telegram / Slack / Email 等外部投递（与 §1.3「不做消息平台」一致）；表单里的"投递目标"以只读说明呈现，不提供选择器。等消息平台立项后再扩。

## 6. 交互细节

### 6.1 指针与焦点

- 所有可点元素 `cursor: pointer`（在 Button/菜单原语内统一，调用点不写）。
- 焦点环：`outline: 2px solid var(--c-accent); outline-offset: 2px`，只在 `:focus-visible` 出现。
- 禁止用 `outline: none` 而不给替代。

### 6.2 hover / active / disabled

| 态 | 表现 |
|---|---|
| hover | 背景换 `--c-hover`（实色），**当帧生效**，无过渡 |
| 离开 | 100ms `ease-out` 回到原色 |
| active | `--c-hover` 再深一档（`--c-line` 混 50%） |
| disabled | `opacity: .45` + `cursor: not-allowed`，不做其他变形 |

### 6.3 键盘

| 键 | 行为 |
|---|---|
| `Esc` | 关闭最上层可关闭元素（弹窗 → 下拉 → tooltip），一次只做一件事 |
| `Enter` | 输入框提交；弹窗内确认；菜单内选中 |
| `Shift+Enter` | 输入框换行 |
| `Ctrl/Cmd+K` | 命令面板（落地后） |
| `Ctrl/Cmd+B` | 侧栏收起/展开 |
| `Tab` | 焦点顺序遵循视觉顺序；覆盖层内**焦点陷阱** |

### 6.4 反馈时序

- 直接操作先改视图（乐观更新），失败时回滚并给出可见错误，**不做静默失败**。
- 提交类动作：按钮立即进入 busy 态（`aria-busy`），禁止重复提交。
- 超过 400ms 的操作才显示 Spinner（避免闪烁）。

### 6.5 文案

- 用户可见文案里禁止出现：内部键名（`profiles.active`）、文件路径（`config.yaml`）、节点名、枚举值。
- 状态词统一：`可用 / 不可用 / 已启用 / 已暂停 / 运行中 / 等待审批 / 已完成 / 失败`。
- 按钮用动词短语：`保存更改`、`测试连接`、`立即运行`；不用 `确定`、`提交`。

### 7.4 EmptyState

### 7.5 ConfirmDialog

`--r-overlay` + `--sh-overlay`；标题 15 + 说明 13 + 危险动作说明；底部右对齐 `取消` / `确认`；打开后焦点落在主按钮；`Enter` 确认、`Esc` 取消；异步 `onConfirm` 自带 pending → 成功关闭 / 失败内联报错。**禁止 `window.confirm`**。

### 7.6 Switch / SegmentedControl / ListRow

- `Switch`：裸开关 36×20，无文字包裹；`aria-label` 必填。
- `SegmentedControl`：容器 `--c-sunken` + `--r-control`，选中项 `--c-raised` + 极小阴影；用于 2–4 项互斥选择（页签、模式、筛选）。
- `ListRow`：高 52（紧凑 36），左 label 13 + 可选副说明 12，右控件；**行间无分隔线**。

### 7.7 图标

- 统一从 `components/icons.tsx` 取，全部改为 `viewBox="0 0 24 24"`、`stroke-width: 1.5`、`size` 默认 16。
- 视觉尺寸只允许 14（行内）/ 16（默认）/ 20（面板标题）/ 32（空态）。
- 删除 `Sidebar.tsx:292-306` 两处内联手写 `<svg>`（现状 18px viewBox 24，与其余 12px viewBox 12 冲突）。

## 8. 可访问性

- 正文与背景 ≥ 4.5:1；大字号（≥18.66px 加粗或 ≥24px）≥ 3:1；装饰性元素不进对比度考核。
- 所有图标按钮有 `aria-label`；纯图标链接禁用。
- 状态变化用 `aria-live="polite"`（审批出现、任务完成），错误用 `assertive`。
- 覆盖层：`role="dialog"` + `aria-modal="true"` + 焦点陷阱 + 关闭后焦点归还触发元素。
- 列表/标签使用正确的 `role`（`tablist` / `tab` / `tabpanel`）。
- 颜色不是唯一信息载体：状态点必须配文字或 Badge。
- `prefers-reduced-motion` 与用户偏好"减少动效"都要生效。
