# 隐私、威胁模型与已知限制

适用当前 v1.0 候选，实际隔离能力见 [架构 §20.7](../../ARCHITECTURE.md#207-平台能力矩阵与阶段门t822026-10-12-冻结)。
本机单用户、单进程、单 worker 是受支持形态。默认回环地址；显式开放非回环不提供鉴权，
不把它称为受支持的公网或多人服务。

## 信任边界

本机用户、其 OS 账户和本机数据目录是可信边界。仓库文件、网页、技能正文、工具输出、模型回答
是数据来源，不能凭其中一段指令获得权限。模型的动作要经过服务端校验、路径策略、审批与执行记录。
客户端按钮不是授权真源；刷新/SSE 重连不应重做副作用。

三档均允许显式本机外部绝对路径的读取、列目录与搜索；敏感文件仍拒绝读取。
外部写目录由设置中的 read_write 授权控制（含子目录、可撤销），只读档仍不许写。撤销写授权不影响读取；
旧 read 记录仅保留兼容。默认搜索、自动 RAG 与委派 scope 不扩大，不自动扫描其它盘，也不支持外部 UNC。
受保护文件不因审批放行；取消阻止后续执行并尝试终止已登记进程树，
不能撤销先前的文件修改、Git 提交或其它已发生副作用。崩溃后不确定任务要求人工核对，不自动重跑。

这些是工具治理。Shell 命令及其子进程拥有当前 OS 用户权限，**没有网络隔离、
CPU/内存/进程数上限或工作区总磁盘配额**。写侧在 Windows 上另有 OS 级沙箱（按权限档位生效、
不是独立开关），但它只约束**写**、不隔离读与网络，非 Windows 上不存在，也不能替代容器。
审批不能证明任意命令安全，工具路径检查也不能限制
任意程序内部读写。第三方 SDK 自建进程不等于已登记进程；不宣称“完全隔离”。

只读档可补齐工作区及已授权目录的普通用户读取 ACE，但不携带任何可写 SID。普通子目录无法枚举时，
仅说明其实际写权限和内部保护范围未核实；不能把“跳过”当成不可写的证明。受保护子树写拒绝项建立失败时阻止命令执行。
物化采用每进程扫描一次与根 ACE 继承：首次扫描后新建的凭据子树需下次进程启动才加入拒绝项，
不是按目录名称实时拦截。完全放行档的 Shell 无 OS 写边界，文件工具的逐目录外部授权不能约束命令内部读写。

文件工具现共用 `SecurityPolicy.files` 进程内后端，实际文件访问前复核目录授权、敏感目标与档位，
变更另核对批准，编辑在原子发布前再核对版本；这不新增内核读隔离。递归删除父目录的批准不能删除其中的
受保护/敏感子目标；只读档不能通过搜索 save_full 落盘。宿主进程恶意并发替换路径仍存在 TOCTOU 窗口。
普通脚本在允许的写范围内可以删除或覆盖文件，命令模式识别不能提供逐项文件审批保证。

## 原文与密钥

聊天、工具原始结果、Checkpoint、长期/中期记忆、检索落盘结果和工作区产物可能保留原文；
这些是可信本机数据，不能作为公开无秘密附件。数据库没有应用级全盘加密承诺，备份包含同样的原文。
页面/HTTP/SSE/日志展示按已实现的已知密钥与规则脱敏，不保证识别所有未知秘密字符串。

页面录入的模型 Key 存 OS 凭据或当前进程内存，设置库只留引用。旧 `.env`/环境变量方式仍可用，
`.env` 是明文私有文件。原始启动堆栈可能包含路径和异常信息，分享前检查。显式诊断摘要只给固定提示，
不读 .env/OS Key、不输出配置正文；它不替代所有日志的人工检查。

## 哪些动作可能联网

| 动作 | 数据与出口 | 需要 Key / 离线边界 |
| --- | --- | --- |
| 提交消息或需要模型的工作流 | 模型实际上下文：问题、历史、所选文件/工具证据及配置的记忆，发往所选端点 | 按连接鉴权；无 Key 的本地兼容端点仍需你部署模型 |
| 模型连接测试 | 固定探测请求到你配置的模型接口 | 显式测试，不因打开设置自动调用 |
| 兼容 API Embedding/显式测试 | 原文字符串数组或固定测试文本到配置端点 | 按环境变量 Key；可能计费 |
| 本地 ONNX Embedding | 在本机计算；缺权重时 SDK 可能下载模型与附属文件 | 离线需已缓存且 local_files_only=true；打开设置不代表权重就绪 |
| 联网检索与抓取 | 查询词发往配置的搜索服务，抓取目标网页 | **常态能力**（2026-10-14 起出厂即开、不可关闭），闲聊与 Agent 都可用；HTTP/HTTPS 与 SSRF 校验、外部内容按不可信数据处理，不是网络沙箱 |
| run_shell 或命令内部 SDK | 取决于获批/实际执行的程序，可自行联网 | 当前无网络出口隔离；安装依赖/下载模型也可能联网 |
| 查看本地历史/地图/数据中台、兼容检查、诊断 | 本地读取/展示 | 本身不新增模型调用；不承诺整个 OS 或第三方 SDK 全局断网 |

不宣称“只访问模型接口”。当前可选第三方 SDK 的全部遥测/网络行为未逐项验收；
“本地部署”描述服务运行位置，不表示所有启用能力均离线。联网或 Key 条件应按当前连接、
Embedding 设置和服务端能力面判断，不根据档位名称作保证。

搜索默认 `auto`：存在独立 Tavily 密钥时，将查询词、时间与域名筛选发送到固定 Tavily Search API；
没有密钥时使用 Bing HTML 兼容搜索。结果正文由本机读取，不默认调用远端 Extract。
显式指定的后端失败不会隐式切换至另一收费服务；密钥仅从环境变量读取并加入现有脱敏集合。
本轮检索/读取次数由配置硬上限约束，失败也计入尝试次数。尚未实现动态浏览器读取和网络出口隔离。

`application/service.py`；进程登记在 `security/process_guard.py`；脱敏出口在投影与服务层；
原文允许本地持久化口径在架构 §20.3。
