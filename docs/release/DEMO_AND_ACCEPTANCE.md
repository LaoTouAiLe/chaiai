# 演示脚本与新机器验收模板

当前材料是可复现脚本，未录制视频、未完成新机器 v1.0 验收。替身模型展示的是界面、
实际服务与编排，不能用于宣称模型回答质量。使用虚构工作区，不出现 Key、真实会话或私人路径。

## 本机工程演示（约 5 分钟）

先在 `frontend/` 运行 `npm run build`，回到 `local-agent-web/`。确认演示端口未被其它服务使用，
不要为了演示关闭不属于本任务的进程。测试服务绑定回环，数据使用自有临时目录；不要传正式数据路径。

1. **说明环境（20 秒）**：展示兼容检查结果和显式诊断。说明目前是候选源码/替身模型。
   初始设置模式另以无 YAML 的隔离环境展示；缺连接仍能打开设置，未录入 Key 不执行模型任务。
2. **对话与刷新（40 秒）**：运行下面的普通假服务，访问 `http://127.0.0.1:8123`。
   新建会话，发两轮消息，刷新，核对每轮只保留一份；展示模式和档位设置。
3. **只读调查（60 秒）**：停止自己的普通假服务，启动工作流假服务，访问 `http://127.0.0.1:8147`。
   新会话选择“执行方式 → 只读调查”，相对文件匹配 `docs/*.md`，关键词分别填写“取消”“能力”，
   提问“核对取消与权限原文”。查看工作流进度、证据与模型 0，刷新核对。
4. **审批修改与验证（60 秒）**：工作流服务另开新会话，选择“代码修改与验证”，源码路径
   `bounds.py`，测试路径 `test_bounds.py`，预期测试数 `3`，提问“修复 clamp 边界并验证三个测试”。
   等待审批，刷新后选择“允许一次”，展示真实工具结果与三个测试通过。模型提案是固定替身。
5. **取消与恢复边界（40 秒）**：说明取消不撤销副作用、崩溃后不确定任务必须核对。
   本轮自动证据用 `test_cancellation.py` / `test_recovery.py`；普通假服务回答太快时不要伪造
   录屏里的“正在取消”。需要录制长任务取消时，另准备可控阻塞的隔离演示，当前未录制。
6. **数据维护与边界（60 秒）**：展示固定评测报告、维护指南、平台矩阵。
   备份→恢复→读历史→续聊已有 CLI 测试，不拿单个 SQLite 备份称为完整机器迁移。
   展示本地历史/会话地图/数据中台入口时说明只读与真实用量缺失的“未知”口径。

```powershell
.venv/Scripts/python.exe scripts/check_release_contracts.py --check
.venv/Scripts/python.exe scripts/serve_fake.py --port 8123
# 普通服务退出后，再启动独立工作流服务：
.venv/Scripts/python.exe scripts/serve_workflow_fake.py --port 8147
```

演示依赖已有开发环境中的测试替身；它不是普通用户分发入口。
相同路径/字段已由 `frontend/e2e/workflow-live.spec.ts`、`conversation-live.spec.ts` 和
`capabilities-live.spec.ts` 使用真实 API 服务验证。取消/备份步骤没有录屏时明确使用测试证据。

## 固定评测与可复现证据

```powershell
# 在 local-agent-web/ 执行；每次使用一个不存在的新报告目录。
.venv/Scripts/python.exe scripts/run_release_evaluation.py --output eval/v10-fixed-first
.venv/Scripts/python.exe scripts/run_release_evaluation.py --output eval/v10-fixed-second
```

比较两个 report.json 的 `source_sha256`、case class/name/status 和 compatibility；
`passed=true` 要求所有预期行为匹配，无跳过/失败/错误，源码执行前后不变。
指标仅针对固定替身集合，原始 JUnit/log 留在本地，不输出真实会话正文。
架构图复用 [架构文档](../../ARCHITECTURE.md)；所有对外能力陈述对应测试/契约，
未做的 OS 沙箱、真实语义质量和新机器结果不能写成简历成果。
