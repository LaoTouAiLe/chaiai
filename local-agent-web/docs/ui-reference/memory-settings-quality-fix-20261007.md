`src/local_agent/reflection/reflector.py:108` 允许实体内容直接返回 JSON 对象，由代码序列化成内部仍使用的规范字符串；合法旧字符串继续兼容。三种记忆提示统一说明对象格式，避免双层转义。`TaskMemoryCandidate`（`:117`）在新任务提取中校验非空内容、实体必需字段、有限的 0–1 数值以及规范 JSON 值。`TaskMemoryDecision`（`:272`）使用这个契约，错误会进入原有最多一次重试，而不是等到写库才发现。

`extract_task_memory`（`:278`）仍保留主对话前缀、末尾指令及原工具定义；合法输出只调用一次。来源事件由系统补齐，作用域授权与写入审核不变。两次非法输出仍明确记审核失败，不冒充保存成功，也不抹掉已完成的任务回答。

旧反思/闲聊的候选保持逐条写入与拒绝报告；没有把旧候选整个批次强制套入新任务契约。两个原有写入拒绝用例显式验证旧循环恢复路径；新增完整新循环失败用例验证新错误路径与任务终态。原有闲聊“合法一条 + 非法一条”用例保留原断言、通过。
