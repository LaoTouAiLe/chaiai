chaiai —— 本地运行的 AI 助手
========================================

这是一个在你自己电脑上运行的网页版 AI 助手。内容都在本机处理，不需要注册账号，
除了你自己在设置里填写的模型接口之外，程序不会把内容发到别处。

适用系统：Windows 10 / 11（64 位）。不需要安装 Python、Node 或其它任何软件。


怎么启动
----------------------------------------
1. 把整个文件夹解压到任意位置（路径里有中文或空格都可以）。
2. 双击 chaiai.exe。
3. 会弹出一个黑色窗口，请让它开着——关掉窗口就等于退出程序。
4. 稍等几秒，浏览器会自动打开页面。如果没有自动打开，就在浏览器地址栏里输入：
       http://127.0.0.1:8000


第一次使用：填一个模型
----------------------------------------
在页面里打开「设置」→「模型连接」，添加一条连接，需要填：

   显示名称    随便起，方便你自己认
   端点地址    你的模型服务地址，形如 https://api.example.com/v1
   模型名称    例如 deepseek-chat
   API Key     你自己的密钥（本程序不提供密钥，也不替你购买）

保存后可以点「测试连接」确认能不能用。保存立即生效，不需要重启程序。


怎么用
----------------------------------------
1. 先选一个工作区目录（你想让它读写的文件夹），再新建一个会话。
2. 直接在输入框里提问。
3. 如果它要修改文件或执行命令，页面会弹出一张「需要你确认」的卡片，写清要做什么；
   你点批准或拒绝。你不点，它不会动你的文件。
4. 左侧可以管理会话（改名、归档、恢复），工作区也可以改名或从列表里移除
   ——移除只是从列表里拿掉，不会删除你的文件。


你的数据放在哪
----------------------------------------
· 会话、设置、记忆：C:\Users\<你的用户名>\AppData\Local\chaiai
· API Key：保存在 Windows 凭据管理器里，不写成明文文件，也不放在程序目录里
· 程序目录里没有任何你的数据，所以以后换新版本时可以整个替换，数据不会丢


隐私与联网
----------------------------------------
· 服务只监听本机地址（127.0.0.1），同一局域网里的其他人访问不到。
· 除了你配置的模型接口，程序不会对外发起请求。


这一版的已知限制
----------------------------------------
· 正在执行的任务不能中途停止；关掉窗口会直接结束程序。
· 同一时间只能运行一份：再双击一次会提示「已经有一个服务在跑」。
· 同一个会话一次只能跑一个任务，任务进行中不能再提交新消息。


出问题怎么办
----------------------------------------
先看那个黑色窗口里的文字，启动失败的原因会写在那里，一般照着提示就能解决：

· 出现「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
  这个程序没有购买代码签名证书，属于正常提示。
· 提示端口被占用：说明 8000 端口被别的程序占了，先关掉那个程序再启动。
· 提示已经有一个服务在跑：说明你已经启动过一份，去任务栏或那个黑色窗口找找。

关于这个压缩包
----------------------------------------
· MANIFEST.txt   本包内每个文件的清单与校验值，可用来核对传输是否完整。
· BUILD_INFO.txt 记录了这份包是用什么环境构建的，排查问题时有用。
