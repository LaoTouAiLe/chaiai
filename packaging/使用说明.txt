chaiai —— 本地运行的 AI 助手
========================================

这是一个在你自己电脑上运行的 AI 助手，界面是本地程序窗口（不是网站，也不需要联网注册账号）。
模型上下文会发送到你配置的端点；其它联网行为见下面的「隐私与联网」。

适用系统：Windows 10 / 11（64 位）。不需要安装 Python、Node 或其它任何软件。


两种安装方式
----------------------------------------
· 安装包（chaiai-setup-<版本>.exe）——推荐
  双击按向导装好，开始菜单里有入口，也能从「设置 → 应用」里卸载。
· 绿色包（chaiai-<版本>-win64.zip）
  解压到任意位置（路径里有中文或空格都可以），双击里面的 chaiai.exe。


安装版：怎么装
----------------------------------------
1. 双击 chaiai-setup-<版本>.exe。
2. 如果 Windows 提示「已保护你的电脑」，点「更多信息」→「仍要运行」。
   这个程序没有购买代码签名证书，属于正常提示。
3. 按向导走：可以改安装位置（建议保持默认的用户目录，那里不需要管理员权限）；
   可以勾选是否创建桌面快捷方式。
4. 装完会直接启动。之后从开始菜单（或桌面快捷方式）打开即可。

安装位置默认在：C:\Users\<你的用户名>\AppData\Local\Programs\chaiai
不需要管理员权限，也不会往系统目录写东西。


启动后你会看到
----------------------------------------
· 正常情况下直接出现一个程序窗口，标题是 chaiai。
· 如果窗口没能起来（例如系统缺少 WebView2 组件），它会自动改用默认浏览器打开页面，
  同时留下一个黑色命令行窗口——那个窗口代表服务在跑，关掉它就等于退出程序。
· 两种情况都可以在浏览器里手动访问 http://127.0.0.1:8000 使用同一个工作区。
· 同一时间只能运行一份：再启动一次会提示「已经有一个服务在跑」。


第一次使用：填一个模型
----------------------------------------
在窗口里打开「设置」→「模型连接」→「添加连接」，需要填：

   名称          随便起，方便你自己认
   端点（base_url） 你的模型服务地址，形如 https://api.example.com/v1
   模型 ID       供应商文档里的模型名，例如 deepseek-chat
   上下文窗口     必填，按模型文档里的窗口大小填，不要猜；必须大于输出上限
   密钥          你自己的密钥（本程序不提供密钥，也不替你购买）

保存后点「测试连接」可以确认能不能用。测试会真的请求端点三次（聊天、工具、流式），
可能产生少量费用；它不执行工具、不写记忆。
模型连接不做预设，其余设置首次启动就有一份可用的默认值（见下面「默认设置」）。


默认设置
----------------------------------------
· 权限：工作区可写（只读 / 工作区可写 / 常规免审三档，可在设置里改）
· 执行：每轮工具循环上限不限；同一动作连续失败 2 次后反馈给模型；命令超时 60 秒
· 自动代码检索：开启（只管任务开始前的那一次；模型自己也能用 grep / glob）
  随包自带 ripgrep，检索读的是当前磁盘内容，不建持久索引
· 联网：出厂即开；检索方式默认「自动」——配了 Tavily 密钥就用 Tavily，否则用网页版检索。
  也可以在「设置 → 联网检索」里显式选 Tavily 或 DeepSeek 搜索 API（各自单独录密钥）；
  DeepSeek 不参与「自动」判定，选它必须自己录密钥，失败不会偷偷换后端
· 记忆：长期记忆开、中期记忆关；上下文压缩阈值 0.8、保留最近 8 轮
· 外观：浅色主题、标准字号、界面动画开、Enter 发送、Think 默认收起

这些都能在「设置」里改，保存后按各自的分区说明生效（外观立即生效，执行/检索/记忆从
下一次新任务生效，正在跑的一轮不受影响）。


怎么用
----------------------------------------
1. 先选一个工作区目录（你想让它读写的文件夹），再新建一个会话。
2. 输入框左下可以选「闲聊」或「Agent」：闲聊只读文件，Agent 可以执行受控工具。
3. 直接提问。需要审批的动作会弹出卡片，写清要做什么；你点「允许一次」或「拒绝」。
   高风险删除还要再勾一次确认。批准只对那一次调用生效。
4. 运行中想停，点「停止生成」；停止不撤销已经发生的工具调用。
5. 左侧可以管理会话（改名、归档、恢复、会话地图），工作区也可以改名或移除
   ——移除只是从列表里拿掉，不会删除你的文件。
6. 它能做的还有：操作一个独立的 Edge / Chrome 浏览器、启动可交互的后台进程、
   看「数据中台」里的记忆与 Token 用量。浏览器与进程能力缺依赖时，页面会说明怎么装。


你的数据放在哪（卸载不会删）
----------------------------------------
· 会话、设置、记忆：C:\Users\<你的用户名>\AppData\Local\chaiai
  - 设置库：data/model_settings.sqlite
  - 会话与检查点：data/checkpoints.sqlite
  - 长期记忆：data/memories.sqlite
· API 密钥：保存在本机设置库里（明文，仅本机），不会进入日志、导出与截图。
  页面只显示「已配置 / 未配置」，只能覆盖写入、不回读。
  如果启动时拿不到设置库，密钥会降级成「仅本次进程内」，重启后要重新录入。
· 程序与数据是分开的：升级、卸载、换一个解压位置都不会动这个目录。
  想彻底清理，请自己删除 %LOCALAPPDATA%\chaiai；重要会话建议先备份 data 目录。


升级与卸载
----------------------------------------
· 升级：下载新版本的安装包，直接安装覆盖即可（版本号不同也不用先卸载）。
  安装程序会提示关闭正在运行的 chaiai——Windows 不允许替换运行中的程序。
· 卸载：开始菜单里点「卸载 chaiai」，或「设置 → 应用」里找到 chaiai 卸载。
  卸载只删程序，**不会删**上面的数据目录。
· 绿色包升级：关掉程序，用新解压的文件夹替换旧的即可；数据同样不在程序目录里。


隐私与联网
----------------------------------------
· 服务只监听本机地址（127.0.0.1），同一局域网里的其他人访问不到。
· 模型与远端 Embedding 会发送上下文或原文到配置端点，显式测试也可能计费。
· 联网检索是常态能力：检索与抓取会访问搜索服务及目标网页，抓取前会校验目标地址。
  若把「网页抓取方式」改成 DeepSeek 抓取，要读的网址会发送给对方、按次计费，且对方跟随重定向后的
  最终地址不在本机校验；默认的「本机抓取」不发网址。
· 命令可以自行联网；当前没有网络隔离与 CPU/内存资源上限。写侧在 Windows 上有 OS 级沙箱
  （按「设置 → 权限」的档位生效，不是单独开关），但它只约束写，不隔离读与网络。
· 本地库、检索结果和工作区可能含原文。备份、日志与截图分享前请检查。


这一版的已知限制
----------------------------------------
· 取消会中断本轮，但不撤销已经发生的副作用；不确定的结果按页面提示人工核对，不会自动重跑。
· 中期记忆的向量库已随包，但启用前要在「设置 → 向量库与 Embedding」里配置一个
  兼容 API 的 Embedding；本地 ONNX 模型不随包（需要自行安装依赖并下载权重）。
· 持久进程使用标准输入 / 输出交互，不提供 Vim 这类全屏终端仿真。
· 浏览器使用独立的登录状态，不借用你个人浏览器的配置。
· 同一时间只能运行一份：重复启动会提示「已经有一个服务在跑」。
· 同一个会话一次只能跑一个任务，任务进行中不能再提交新消息。
· 窗口依赖系统的 WebView2 组件（Win10/11 一般自带）；缺失时会改用浏览器，功能不受影响。
· 没有自动更新：新版本需要自己下载安装包。
· 非 Windows 系统没有 OS 级写边界；本包只面向 Windows。


出问题怎么办
----------------------------------------
先看程序窗口里的提示，或者数据目录下的这两个文件：

· 启动错误.log    程序没能起来时写，里面有失败原因
· 模型调用失败.log 模型请求失败的原因（只记摘要，不记密钥和上下文正文）

常见情况：
· 「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」（未签名程序的正常提示）。
· 提示端口被占用 → 8000 端口被别的程序占了，先关掉那个程序再启动。
· 提示已经有一个服务在跑 → 你已经启动过一份，去任务栏或开始菜单找找。
· 想看环境摘要而不启动服务：在安装目录里执行
      chaiai.exe --diagnose
  它输出一段 JSON，检查配置、前端产物、三个数据库与依赖；不读取密钥。
  绿色包在 exe 所在目录执行同一条命令。

错误日志可能包含本机路径或原文，分享前先检查并隐藏私人信息。


关于安装包里的文件
----------------------------------------
· MANIFEST.txt   包内每个文件的清单与校验值，可用来核对传输是否完整
· BUILD_INFO.txt 这份包是用什么环境构建的，排查问题时有用
· 使用说明.txt   本文件
