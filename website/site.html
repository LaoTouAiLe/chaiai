能力01 / CAPABILITIES

不是聊天框，是一个工作台

对话只是入口。真正干活的是工具、浏览器、后台进程，以及它们在本机留下的记录。

01

工具执行与逐条审批

常规命令直接执行；删除、覆盖已有文件、破坏性 Shell 与大范围编辑必须人工批准 —— 任何设置下都不免。

批准、拒绝、改参数都由你决定，动作留痕

02

浏览器操作

驱动一套独立的 Edge / Chrome：打开页面、填写表单、点击与截图都能做，登录状态与你的个人浏览器分开。

缺依赖时说明怎么装，不静默失败

03

持久进程与后台服务

启动一个需要持续输入的服务，读取它的输出、出错时停掉；运行文件收在自忽略的 .agent-runtime/，不污染工作区。

标准输入输出交互 · 不做全屏终端仿真

04

联网检索与网页读取

检索与抓取是常态能力，闲聊与 Agent 两种模式都可用；每次抓取前都先校验目标地址，重定向前后再各查一次。

页面按轮展示搜索来源、已读取内容与回答引用

05

会话地图与分支追问

对话长成一棵树：父节点在左、卡片向右展开；从任意一轮继续提问会新增子分支，原来的路径完整保留。

分支可改名与排序，文件与记录不随分支回滚

06

数据中台：记忆、任务与用量

概览、中期记忆、长期事实、任务结论与 Token 用量放在一处；按工作区、状态与日期筛选，缺数据的地方不补零。

只读展示 · 统计口径与上限如实标注

07

记忆与上下文压缩

短期对话、中期向量记忆与长期事实分层保存；上下文接近窗口上限时自动整理历史，保留结论与近期往来。

整理过什么会写在页面上，刷新也能回看

08

任务可取消，重启不重跑

运行中的任务可以停止生成或整体取消；被中断的任务会被明确标记出来，绝不会在你不知情时自动重跑。

停止不撤销已经发生的工具调用

安全边界02 / SAFETY

权限写在规则里，不写在提示词里

工具执行、作用域判定与安全判据都在服务端；浏览器不直接操作你的文件，也不替你解释执行状态。 权限按"能写到哪"分三档：只读、工作区可写（默认）、常规免审 —— 本机外部路径默认可读， 写入范围与 Shell 的写侧沙箱随档位变化，往工作区外写还要逐目录授权。

外部内容一律按不可信数据处理：页面里的任何文字都只是数据，不能改变目标、规则与安全策略，也不能跳过人工审批。

默认放行
  • 工作区内的读取、写入与检索（默认档）
  • 本机外部路径的读取与搜索（敏感文件除外）
  • 常规命令（破坏性命令除外）
  • 联网检索与网页读取（抓取前先校验目标地址）
始终需要批准
  • 删除文件或目录、覆盖已有文件
  • 破坏性 Shell 与大范围编辑
  • 工作区外的写入（需先在设置里授权该目录）
  • 受保护目标与敏感文件（授权也不放行）

破坏性命令名单由代码层底线保证：只能追加，不能取消；受保护目标与敏感文件不因审批放行。

架构03 / ARCHITECTURE

两层界面，一支执行链

生产运行只需要 Python 服务与前端产物，不需要额外启动 Node 服务。

  1. 浏览器

    React 界面

    会话、轨迹、审批与设置；只发请求，不碰文件。

  2. 服务端

    FastAPI

    静态产物、API 与安全判据的唯一入口。

  3. 执行

    LangGraph

    按轮推进：Think、工具、计划、审批与用量。

  4. 本地数据

    本机存储

    对话与运行记录只落在本机，不经过第三方中转。

开始使用04 / GET STARTED

准备、连接、提问

不需要注册账号。启动服务后，在网页设置里填一次模型连接就能提问：发行包按随包说明安装； 从源码运行则是装依赖、构建前端，再启动 Python 服务。

  • 模型、密钥与权限都在网页设置里维护，随时可以撤销
  • 密钥只保存在本机，不进入日志、导出与截图
  • 对话、记忆与运行记录都存放在本机
下载 Windows 安装包 从源码运行

安装包没有代码签名：SmartScreen 会提示「未知发布者」，点「更多信息 → 仍要运行」即可。

启动完成 
chaiai 正在启动…
✓ 本地服务已就绪
→ 用浏览器打开 127.0.0.1:8000

服务只监听本机回环地址：同一网络里的其他设备也访问不到。

三步走 
① 安装    取得发行包，或按源码说明装依赖并构建前端
② 连接    在网页设置中填写端点、模型名与密钥
③ 提问    指定一个工作目录，让它在那里干活

安装方式与版本要求以随包文档为准；服务自检可运行 python -m local_agent.api --diagnose。

设计原则05 / PRINCIPLES

把克制写进默认值里

这些不是功能介绍，而是它做每一件事时都会遵守的约束。

  • 本机优先默认只监听本机地址，对话与执行记录不经过第三方中转。
  • 人在回路有副作用的动作一律停在你的批准之前，不存在"悄悄执行"。
  • 有据可查每一次执行、批准与失败都留下可回看的记录，不做静默处理。
  • 最小授权只申请完成当前这件事所需的权限，读与写分开，随时可以收回。
  • 显式失败出错时给出可读的原因与下一步，不用沉默或猜测糊过去。
  • 随时可停运行中的任务随时能停下来，停下来也不掩盖已经发生的事。
