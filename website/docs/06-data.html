数据中台

把记忆与用量放在一处看：五个页签，全部只读，缺数据就如实写「未知」。

五个页签

侧栏「数据中台」：概览、中期记忆、长期事实、 任务结论、Token 用量。

  • 概览：最近的模型调用、实际输入 / 输出 Token、缓存命中率。
  • 中期记忆 / 长期事实：按工作区、状态与关键词查看已保存的内容与详情。
  • 任务结论：每轮任务留下的结论与其来源。
  • Token 用量：按工作区、日期与模型筛选，明细到单次调用。

筛选与翻页

  • 记忆相关：按「记忆工作区」、记录状态筛选，或按名称 / 正文关键词搜索。
  • 用量相关：按「用量工作区」、开始 / 结束日期与模型筛选；用量日期按 UTC 计算。
  • 列表分页，底部有「上一页 / 第 n 页 / 下一页」；右上角「刷新数据」重新读取。

用量怎么算

  • 包含归档会话与各条分支；同一次共享调用会去重，不会因为出现在多个分支里被重复计数。
  • 指标卡有「模型调用」「实际输入 Token」「实际输出 Token」「缓存命中率」；明细里还有调用次数、未命中输入、缓存读取。
  • 没有数据的地方显示「未知」或空态，不补零——「0」和「没读到」是两件事。

看不到数据时

  • 显示「数据暂时无法读取」：检查服务是否在运行，然后点「刷新数据」。
  • 日期提示「开始日期不能晚于结束日期」：调换两个日期。
  • 当前会话仍在执行或等待审批时，这里只展示数据，处理请「返回会话」。
边界：第一版只读——不提供记忆写入 / 删除、向量库重建与费用换算。 打开本页与浏览筛选不会新增模型调用；真实数据规模下的性能、以及缓存效果尚未验证。
